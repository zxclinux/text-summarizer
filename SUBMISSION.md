# LLM Project, Basic Level: Text Summarization

**Live service:** <RENDER SERVICE URL>

This project is a web app that produces a concise summary of an input text with a single language model call. It uses the OpenAI `gpt-4o-mini` model through the official `openai` SDK (`chat.completions.create`). The logic lives in a standalone, UI-independent `Summarizer` class, while the model, temperature and limits are kept in a `Settings` config that is injected as a dependency and can be overridden with environment variables. The UI is built with Gradio (`gr.Blocks`): the user enters their own API key (a password field; the key is never stored), pastes a text, picks a summary length (1-2 sentences, 3-5 sentences or a paragraph) and gets the result with a copy button. To make sure the user sees only the summary, without preambles like "Sure, here is the summary...", the app uses a strict system prompt that forbids introductions and comments, a low temperature (0.2) and `.strip()` on the response. The prompt also requires the summary to be written in the same language as the input. Common errors (empty key or text, invalid key, rate limit, network problems) are shown as clear messages instead of crashing the app. Limitations: input is capped at 30,000 characters, a personal paid OpenAI key is required, and summary quality depends on the chosen model.
